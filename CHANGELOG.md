# Changelog

## 0.1.0 — 2026-10-06

First public release of Moyu Office, derived from Star Office UI.

- Local collectors for Codex, DSH, notification signals, training, BetterGI, SRA, ZZZ OneDragon, cloud-drive activity and system metrics.
- ComfyUI queue observer and optional bounded node-progress forwarding extension.
- NetEase Cloud Music title/artist strip above the fireplace; no playback-state detection.
- Secondary-display fullscreen entry using a dedicated Edge profile, with separate browser and service-stop entries.
- Private per-install initialization, loopback binding, Host/Origin checks and explicit unavailable/stale states.
- Windows x64 application bundle, per-user installer, source and portable archives, and release checksums.
- Chinese/English guides, security policies, privacy documentation and preserved upstream attribution and artwork restrictions.

首个公开版本：集成本机状态采集、ComfyUI 节点观察、网易云歌名歌手横条、副屏全屏入口、随机本机密钥、请求边界校验和 Windows 安装包。自定义角色动画及程序专属语录尚未实现。
