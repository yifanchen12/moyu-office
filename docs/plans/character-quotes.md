# 角色特色语录接入方案（已批准）

## 目标与已完成文案
十二位软件角色各有独立语气；已写好 234 条原创中文草案，见 docs/character-quotes.zh-CN.md。覆盖实际支持的开始、持续工作、可读进度、活动暂歇、暂停、异常、恢复、空闲、离线、消息与负载。用户已于 2026-10-07 批准，本文作为实施依据。

## 已核实的复用点
frontend/index.html 的 maybeShowGuestBubble 每 5.2 秒随机选择角色，使用共享状态文案；已有气泡绘制、3.2 秒寿命和移动跟随。localItems 和 /local/status 已提供稳定软件 ID、available、state 及白名单 metrics；已有 last_alert_at、phase、训练 current/total/percent、ComfyUI 当前节点 percent，以及 cpu_percent。不需要新采集器、后端接口或依赖。现有 Phaser、JavaScript Map/时间戳足够。

## 文件边界
- frontend/character-quotes.js：语录数据、纯状态判断与轻量轮换调度，供浏览器和 Node 检查共用；不读取网络、磁盘、聊天或日志。
- frontend/index.html：只接入本地场景的快照观察、气泡选择和跟随绘制；保留演示/上游通用访客逻辑、猫的独立语录、角色游走及详情/启动入口。停止本地软件通用随机语录与新角色语录重复播报。
- tests/character_quotes.cjs：验证状态与事实边界、消息去重、节流、首屏基线、文案轮换和旧事件过期。
- docs/character-quotes.zh-CN.md：完整可审阅文案；实施时同步运行语录与说明。
- 不改 local_bridge.py、local_server.py、local_launch.py、私有配置、素材、安装器及已暂存打包工作。

## 输入、输出与事实边界
输入是既有白名单状态快照和单调前端时间；输出是软件 ID 与短文本，或无待播语录。仅识别已知角色。异常或缺失数据使用 unavailable；未知字段不拼入文案。
首次快照建立基线，不追播旧开始/旧消息/旧完成。活跃转空闲通常叫 settled，不说任务成功。暂停只依据明确 phase=paused。训练 completed 仅在观察期间 current 达到有效正 total 时表示步数完成，不表示模型质量、保存或评估成功。ComfyUI percent 仅表示当前节点，队列转空闲只说活动暂歇。网盘只谈客户端/磁盘活动，不称其为下载速度或完成。消息只依据新的 last_alert_at，不读或推断正文。性能只引用有效 CPU 数值，不声称自动清理或降温。recovered 表示状态/信号恢复，不声称自动修复。

## 轮换与显示
优先异常、新消息、阶段变化，再轮到持续工作/进度和空闲。全局每 8 秒最多开始一条软件气泡，同时最多一条，显示约 4 秒；普通同角色间隔至少 35 秒，紧急阶段仍遵守全局间隔。每个阶段至少三句，避免同角色连续复读。一次轮询不产生重复事件；长时间等待的旧事件和已不适用事件丢弃。气泡跟随角色、自动换行并限制在画面边界内。详情弹窗打开时不抢占展示，关闭后过期事件不会集中补播。

## 实施顺序与验收
1. 完成语录库与独立状态/调度检查，不依赖 Phaser。
2. 接入快照和既有气泡绘制，验证角色 ID、轮换、节流和离线边界。
3. 同步 moyu-office 与 Star-Office-UI；使用正常 Windows 桌面重启服务，保留网易云读取。
4. 运行 node tests/character_quotes.cjs 与 node tests/scene_interactions.cjs；实际房间检查多位不同角色、持续工作/空闲语录、跟随、详情与猫/音乐兼容。只有需要真实事件的分支使用明确测试夹具验证，不启动自动化或训练任务来造状态。

## 已核实与约定
已核实：现有共享气泡逻辑及以上状态字段。约定：本轮中文文字气泡，沿用当前像素字体；不增加语音、人格模型、额外服务、设置面板、安装包构建或自动 GitHub 发布。可用状态有限的角色不会为了用齐文案而捏造阶段。

## 实施结果（2026-10-07）
已接入全部 12 位角色、234 条语录，并同步到 Star-Office-UI 源码副本。独立语录检查和既有场景检查通过，覆盖事实边界、消息去重、节流、轮换、事件过期及真实气泡绘制适配。实际页面观察到 Codex 持续工作语录、QQ 与 DSH 专属语录，确认详情打开时暂停新气泡、关闭后恢复，猫、网易云歌曲栏、游走和详情正常。当前未运行的任务阶段由明确测试数据验证，未额外启动训练或自动化任务。

后续入口排查确认：日常全屏窗口使用 19101，开发副本使用 19100。已补齐安装目录的页面、语录模块和所需角色素材，重启真实的日常服务，并在 19101 页面观察到 DSH 专属语录。F5 只能刷新浏览器；更新部署文件后，也需要重启提供该页面的服务，以清除进程内页面缓存。用户随后明确要求将本轮源码改动提交到 GitHub；安装目录副本与私有配置不纳入公开提交。
