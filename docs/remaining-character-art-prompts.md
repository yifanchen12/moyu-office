# Remaining female software mascots

Mode: built-in image_gen; genuine transparent RGBA outputs, no fallback CLI or API keys. One sheet per original female fan mascot, four idle frames at 4 fps and four walk frames at 8 fps. Existing character sheets provide only the pixel-art look; their identities and costumes are not reused. These are independent icon-inspired designs, not official product characters. Training/performance use functional motifs, because they have no single brand icon.

Used on WeChat, QQ, training, Quark, ComfyUI and performance sheets whose initial frames were too close to the grid boundary. PNGs are never resized or repainted programmatically; the built-in image tool creates each selected edit. Metadata generation only reads PNG alpha and writes frame foot pivots.

Adjust ONLY spacing and alignment of this exact pixel sprite sheet. Preserve this same woman, colors, clothes, details and all eight distinct poses. EXACT 4 columns x 2 rows equal square cells. Make every full-body figure 20% SMALLER inside its cell. Put top of hair at 18% cell height and soles at 85% cell height in BOTH rows, with same head/body scale. Generous genuine transparent margins on ALL four sides of every cell, no pixel touching row boundary or edge. Preserve true alpha. No background, grid, text, other characters or altered style.
