Moyu Office / 摸鱼事务所

This application observes local task metadata and system performance and displays a pixel-art dashboard using the installed Microsoft Edge browser. It does not install or control monitored applications. No administrator rights are required. No Windows kiosk policy or firewall exception is created.

First launch creates private local configuration and random secrets. Configure installation and log paths in local-config.json. Local runtime files and settings are preserved on uninstall. The service listens only on 127.0.0.1.
